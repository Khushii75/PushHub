# PushHub Privacy Policy

**Effective Date: September 12, 2026**

PushHub is a Microsoft Edge extension designed for competitive programmers. Its primary purpose is to help users synchronize their accepted coding solutions from supported competitive-programming platforms to a GitHub repository selected by the user.

This Privacy Policy explains what information PushHub accesses, how that information is used, and the choices users have regarding their information.

## 1. Information PushHub Accesses

### GitHub Account and Authentication Information

When a user chooses to connect GitHub, PushHub uses GitHub's OAuth authorization process.

Depending on the authorization and synchronization process, PushHub may access information associated with the user's GitHub account, such as:

- GitHub username
- GitHub account information required for authentication
- OAuth access and refresh tokens
- Token expiration and authorization scope information
- GitHub repository information needed to perform synchronization

PushHub does not ask users to provide their GitHub password to the extension.

Authentication tokens are used only to maintain the authorized GitHub connection and perform actions requested by the user.

### Competitive-Programming Website Content

When a user uses PushHub on a supported competitive-programming website, the extension accesses the page information required to identify and synchronize an accepted solution.

This information may include:

- Problem title or identifier
- Submitted source code
- Programming language
- Source platform
- Problem URL
- Problem tags or categories
- Other solution metadata required for synchronization

PushHub uses this information only to provide its solution-synchronization functionality.

PushHub does not intentionally collect the user's general web-browsing history or unrelated website content.

### Extension Settings

PushHub stores extension settings required to provide its functionality. This may include:

- GitHub connection state
- GitHub username
- Selected GitHub repository
- Repository identifier and branch information
- Authentication and token information required to maintain the GitHub connection
- Other extension configuration and synchronization state

## 2. How PushHub Uses Information

PushHub uses information only to provide its core functionality.

This includes:

- Authenticating the user with GitHub
- Maintaining the user's authorized GitHub connection
- Identifying accepted competitive-programming solutions
- Extracting the solution and relevant problem metadata
- Creating or updating solution files in the GitHub repository selected by the user
- Organizing synchronized solutions according to PushHub's functionality
- Remembering the user's extension configuration and selected repository

PushHub does not use user information for advertising, creditworthiness decisions, lending decisions, or unrelated purposes.

## 3. GitHub and Other Third-Party Services

PushHub relies on certain third-party services to provide its functionality.

### GitHub

PushHub uses GitHub's OAuth authorization and GitHub API services to authenticate users and access the GitHub repository selected by the user.

When a user connects GitHub, the user is shown GitHub's authorization page and chooses whether to authorize PushHub.

GitHub's own privacy practices and terms apply to information processed directly by GitHub.

### Supported Competitive-Programming Platforms

PushHub accesses relevant content from supported competitive-programming websites when required to identify accepted solutions and provide the synchronization feature.

Supported platforms may include:

- LeetCode
- GeeksforGeeks
- HackerRank
- CodeChef
- Codeforces

PushHub does not intentionally collect unrelated information from these websites.

### PushHub Backend

PushHub uses a backend service to support parts of the GitHub OAuth and synchronization workflow.

The backend may process information necessary to exchange or refresh GitHub authorization information and provide the extension's requested functionality.

The backend is not intended to be used for advertising, general browsing tracking, or unrelated user profiling.

## 4. Data Sharing and Sale

PushHub does not sell user data.

PushHub does not share user data with third parties for advertising, data brokerage, or unrelated commercial purposes.

Information may be transmitted to GitHub and the PushHub backend when necessary to provide authentication, repository access, or synchronization functionality requested by the user.

PushHub does not intentionally transfer user information for purposes unrelated to its stated functionality.

## 5. Authentication and Security

PushHub uses GitHub's OAuth authorization flow rather than asking users to enter their GitHub password into the extension.

Authentication and synchronization requests are transmitted using HTTPS.

OAuth tokens used by PushHub are stored in the browser's extension storage so that the authorized GitHub connection can be maintained between browser sessions.

PushHub does not intentionally expose authentication tokens through its user interface.

Users can revoke PushHub's GitHub authorization through their GitHub account settings.

## 6. User Control

Users decide whether to connect PushHub to GitHub.

Users also choose the GitHub repository that PushHub uses for synchronization.

Users can stop using GitHub synchronization by disconnecting their GitHub account or removing the PushHub extension.

Solutions that have already been synchronized to a user's GitHub repository remain under the user's GitHub account and can be managed or deleted by the user through GitHub.

## 7. Information PushHub Does Not Intentionally Collect

PushHub does not intentionally collect:

- Health information
- Financial or payment information
- Precise location information
- Personal emails, chats, or private communications
- General web-browsing history
- Keystrokes, mouse movements, or unrelated user activity

PushHub only accesses website content required for its stated competitive-programming solution-synchronization functionality.

## 8. Data Retention

PushHub retains information only for as long as it is needed to provide the extension's authentication, configuration, and synchronization functionality.

Information stored locally by the extension can be removed when the user disconnects their GitHub account, clears the extension's stored data, or removes the extension.

Information already written to the user's GitHub repository remains under the user's control and is subject to GitHub's services and policies.

## 9. Changes to This Privacy Policy

This Privacy Policy may be updated when PushHub's functionality, data practices, or third-party services change.

Any updated version will be published at this same URL with a revised effective date.

Users are encouraged to review this policy periodically.
